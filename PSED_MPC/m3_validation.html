Twin validation against measured KB profiles

The KB-parameterised Ylilammi twin (ylilammi_langmuir_channel) is run against every measured conformality profile across all four papers and scored with the same curve engine used across the KB. Missing twin inputs are covariate-imputed from the KB — and because an imputed value is only an estimate, it is a candidate cause of any mismatch, tracked separately below.

Verdict is set by the provenance of the two penetration-setting inputs (dose & gap height): model gap = both measured, twin still misses → real Ylilammi-physics / literature-K,c limit · estimation gap = an input is a KB estimate, which may itself be the cause, not the model · data gap = an input was assumed → measure it · out of scope = plasma / recombination-limited (Arts), which the thermal twin doesn't model — see future work.
