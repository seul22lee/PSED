As P144 (kb/reports/P144_pass0.method.txt), with P145 changes:
(U) pairing per role: evidence overlap, then equal normalized name, then data overlap (a pass-0 unit whose data names a curve the
gold binds to an entity pairs with that entity; only curves have a gold binding: cells and peaks have none). Gold nested simulations
collapse to the top one (gold_shape). ESI-only gold units (evidence in no element of the paper) are listed apart (0 in all three).
(L) a gold table that mixes layouts gets its majority layout, the minority cells listed; a panel with no figures.json data is
"no data in figures.json" (image panels) or "figure stage read nothing" (map/plot/spectrum panels never imported), not compared.
(C) every figures.json curve, cell and peak.
Cell-based units: pass-0 units whose data names a figures.json cell or whose introduced_in names a table cell.
Graph: gold (left) and pass 0 (right); fills: green matched / agrees, amber merged / split / differs, red missing (gold) / extra
(pass 0) / unassigned, grey ESI-only, white not compared; dashed lines pair a pass-0 node with its gold node. Run nodes are listed
one per row (indented tree); only data leaves wrap past 20.
P145_before.*: the P144 pass-0 lines under the P145 pairing (zero calls), for comparison.
Calls: 3, approved ~$0.75.
