FIX 1 the rule and the layout

psed_v2/kb/reports/P156_propose.fix1_rule.txt

Layout: P143 'not_units' = 'The rows are not experiment units: a symbol table (symbol, meaning, value) or a comparison with the literature (cited values).' (ontology/export.py P143_TABLE_LAYOUTS).
Its definition names the columns of a symbol table: ['symbol', 'meaning', 'value']; there is no unit column, so a candidate's unit is its records' unit.
Which cell plays which role is read from the records, not from the position: yli18 tabu1 holds two symbol / meaning groups per row (cells c0 and c2
are different quantities: tabu1.r4c0 symbol D, tabu1.r4c2 symbol v), so a table row groups by (paper, table row, symbol); in the group the cell
whose text is the symbol is the symbol column, the other cell the meaning column. A row's symbol is the pass-1 record's symbol field.
A row of a symbol-table layout is a record of a not_units table that carries a symbol: yli18 tabu1, yim20 tabu1 and yim20 tabu2 (yim20 tab2 and
mat22 tab2, also not_units, have no unmapped rows). yim20 tabu1's ten cells have no printed label (the meaning is only in the record's quote,
'Distance between pillars (m)'): P155 skipped them silently (a row with no label was not a candidate and not reported); they are five candidates now.
A unit row of a cell (field unit, no symbol of its own) takes the symbol of the quantity row of the same cell and label.
Equation / symbol-table merge: a row whose label is its symbol joins the one symbol-table row of its paper with that symbol (8 rows);
else a row whose label (a symbol's: its definition) has the words of one meaning, articles and 'of' dropped and word order ignored, joins it
(0 rows: every equation row of round 1 joined by its symbol first). Check of the rule on the example: words('rate of adsorption')
= ['adsorption', 'rate'], words('Adsorption rate') = ['adsorption', 'rate']: equal. Ambiguous symbols (two rows): 0.
Symbols are local to a paper: R is yli18's gas constant and yim20's diffusion resistance of a channel, F yli18's gas flow and yim20's flux; both
candidates carry the symbol as an alias, so accepting both of a pair would put one alias in two entries (check 4 would fail).

FIX 2 the normalization (grow.py)

psed_v2/kb/reports/P156_propose.fix2_normalization.txt

grow.py (P156), the never match: a never.csv label is split into parts (split_parts), every part normalized (norm_strict) and
compared, equal or not, with the normalized label of each compiled row and symbol-table meaning (norm_strict too). A part that names a live
entry that is not an attribute is superseded and suppresses nothing (never_index).

def strip_latex(s):
    """\\text{...} (and \\mathrm, \\mathit, \\mathbf, \\rm) unwrapped; braces, backslashes and the ^ / _ markers removed."""
    return re.sub(r"[{}\\^_]", "", LATEX_TEXT.sub(r"\1", str(s)))


def strip_trailing_units(s):
    """Every trailing group in [ ] or ( ) removed, the last first ('rho (film density; model input) [kg m-3]' -> 'rho'); never to empty."""
    s = str(s).strip()
    while True:
        t = re.sub(r"\s*(\[[^\[\]]*\]|\([^()]*\))\s*$", "", s)
        if t == s or not t.strip():
            return s
        s = t


def norm_strict(label):
    """FIX 2b, both sides of a never match: trailing unit groups stripped, LaTeX stripped, casefold, whitespace collapsed, a trailing 's' dropped."""
    s = " ".join(strip_latex(strip_trailing_units(label)).casefold().split())
    return s[:-1] if len(s) > 1 and s.endswith("s") else s


def split_parts(label):
    """FIX 2a: a never label that holds several labels, split at ';' outside brackets ('MA; MB [kg mol-1]' -> 'MA', 'MB [kg mol-1]')."""
    parts, depth, cur = [], 0, ""
    for ch in str(label):
        depth += ch in "([{"
        depth = max(0, depth - (ch in ")]}"))
        if ch == ";" and depth == 0:
            parts.append(cur)
            cur = ""
        else:
            cur += ch
    return [p.strip() for p in parts + [cur] if p.strip()]


def never_index(entries):
    """({normalized part: never label}, superseded): every part of every never.csv label, normalized (norm_strict), except the parts that name
    a live entry - its id, name, label or an alias, normalized the same way (FIX 2c) - that is not an attribute: an attribute entry is how
    the pilot stores a never label (check 12), a promoted or ordinary entry is a concept now. Superseded parts are [(never label, part,
    entry ids)] and suppress nothing. never.csv itself is not changed."""
    names = defaultdict(list)
    for e in entries:
        if e.get("attribute"):
            continue
        for t in [e["id"], e.get("name", ""), e.get("label", "")] + [str(a) for a in e.get("aliases") or []]:
            if str(t).strip() and e["id"] not in names[norm_strict(t)]:
                names[norm_strict(t)].append(e["id"])
    parts, sup = {}, []
    for r in X.never_rows():
        for p in split_parts(r["label"]):
            k = norm_strict(p)
            if names.get(k):
                sup.append((r["label"], p, ", ".join(names[k])))
            elif k:
                parts.setdefault(k, r["label"])
    return parts, sup
