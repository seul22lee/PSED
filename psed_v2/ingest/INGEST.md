# Ingest

Ingest turns each in-scope PDF (`corpus/raw/<paper_id>.pdf`, 58 in-scope papers with a PDF on 2026-10-13, plus Guyon 2004, ingested before its exclusion from the scope) into one folder
`ingest/final/<paper_id>/` with the body text, the abstract, the figures with their captions and crops, the tables
with a rule check and a crop, the equations from two tools, and flags wherever the output may be wrong. No LLM is
called. The two local vision models (Marker's OCR, Docling's formula reader) are not reproducible bit for bit, so each
paper is converted once and the result is kept. The numbers of the 58 papers, with Guyon 2004 on its own line outside every total, are in `ingest/NUMBERS.md`; what is still
wrong, and the known limits, in `ingest/ERRORS.md`.

## Rerun

```
psed_marker env:  python ingest/parse_marker.py --all            Marker 2.0 (force_ocr, llama.cpp backend) -> marker/<id>/; once per
                                                                 paper (skips rows with manifest marker = ok; --redo overwrites)
                  python ingest/parse_marker.py --bands --all    band-crop OCR on existing output (captions and abstracts drawn as
                                                                 images); records merged per block into marker/<id>/bands.json
psed310 env:      python ingest/parse_docling.py --fetch-abstracts   OpenAlex abstracts -> corpus/openalex_abstracts.json (network, once)
psed310 env, GPU: python ingest/parse_docling.py --formulas <ids>    Docling layout + CodeFormula on R1/R2 crops -> docling/<id>/equations.json
psed310 env:      python ingest/structure_marker.py --all        marker/<id>/structure.json (captions, figures, tables + check, equations, abstract)
psed310 env:      python ingest/merge.py --all                   final/<id>/ (document.md, structure.json, figures/): line_numbers.py,
                                                                 body_check.py, body_repair.py, the check again on the repaired text
```

Environments: `psed310` (Docling, pdfplumber, pypdfium2, tabulate) and `psed_marker` (marker-pdf 2.0.0 with the
llama.cpp backend, `~/opt/llama.cpp/`; the env variables are in `CLAUDE.md`). `parse_docling.py --formulas` needs a GPU
with about 6 GB free. Progress lives in `corpus/manifest.csv`, column `marker` (ok | failed | blank); the other steps
write no column. Review pages (gitignored): `reports/papers.html` (the output paper by paper) and
`reports/review_body.html` (every body flag with its crop and verdict); generated by `report_papers.py` and `report_body.py`; `numbers_md.py` writes `NUMBERS.md`, `regression.py` checks the
output against the answer set (`--update` rewrites its baseline `answers/flag_keys_baseline.json`).

## Items

**Metadata.** DOI, title, authors, year, journal come from `corpus/manifest.csv` (OpenAlex), never from the PDF.

**Body text** (`final/<id>/document.md`, Marker). Marker's markdown with the running lines removed (10 words or fewer,
identical on 3+ pages, 4+ letters), the band-OCR'd blocks written in, the margin line numbers of a line-numbered
manuscript removed (`line_numbers.py`: a page carries margin numbers when 8+ bare integers stand at one x outside the
text column, rise down the page and cover 70 % of its text lines; a paper is line-numbered when 3+ pages are), and the
two repairs below applied. Then the body check (`body_check.py`) compares the numbers of the decoded PDF text layer
with the numbers of document.md, paragraph by paragraph, in both directions (`body_flags`, `body_check` in
structure.json).

**Abstract** (`abstract`, `abstract_source`). From Marker's blocks: the paragraph under an Abstract heading or after
"Abstract:", else the pages 1–2 block that matches the OpenAlex abstract, else layout and order; the OpenAlex text
when it has 50+ words and the extracted abstract is empty or has recall below 80 % against it.

**Figures and captions** (`captions` with `images`). A block whose text starts with Fig./Figure/Scheme/Table + number
is a caption when Marker labels it Caption, the number is followed by ".", ":" or "|", or a Table caption's number is
followed by a capitalised word; it continues with the Text block directly below (gap ≤ 4 pt, same column) unless the
caption ends a sentence and the next block starts one. A figure is bound by Marker's FigureGroup/PictureGroup, else to
the next caption on the page whose horizontal span overlaps it, else the previous, else the next; a Figure, Picture,
Diagram or ChemicalBlock without an image file is cropped from the page. A manuscript with its figures after all
captions binds them by page order. Captions drawn inside the picture are recovered by band OCR (T1).

**Tables** (`captions` with `table`, `bbox`, `check`, `check_reasons`, `check_detail`, `crop`). Marker's table html
as github markdown (header rows merged with " / ", rowspans and colspans honoured, superscripts as `^`, trailing
zeros kept), the nearest unused table caption on the page, a crop with the caption band above. Rule check against
the decoded text layer inside the box: `ok`, `flag` with reasons, or `not checkable` (a rotated table, a glyph without
a decoding). Flag reasons: numeric tokens of the layer missing from or extra in the markdown (sign, decimals,
exponents; with and without thousands separators) and the counts of ± ↑ ↓ ↗ ↘ ≤ ≥ ≈ ∼ ≪ ≫ ×; letters of the layer the
table lacks; header colspans against body columns, an empty trailing header or column, a short last row, numbers just
below the box on the table's columns; fewer than 5 layer words; no cells (the table block drawn as an image, or a Table caption bound
to no table block at all: a picture, or the caption alone). No exception: footnotes or a hidden duplicate layer inside the box also flag.

**Equations** (`equations[{page, bbox, number, docling, marker, status}]`). Docling's layout gives the formula boxes;
CodeFormula reads our crops (R1 the formula box at 216 dpi, R2 the band of the text column when the box is at most
25 pt wide). Marker's `<math>` blocks and short standalone blocks with a reaction arrow are its equations. `merge.py`
pairs the two on a page by box (IoU and vertical overlap ≥ 0.6), the rest by printed number: `agree` (equal after
notation normalisation), `differ`, `docling only`, `marker only`.

**Text-layer decoding** (`glyph_codes.json`, used by the table check and the body check). Named characters of
symbol-encoded fonts by a table per font family, `(cid:N)` codes by a table per embedded subset, every entry checked
on a glyph crop (`reports/glyph_evidence/`); glyphs viewed and left undecoded are listed with the reason. A font whose named
characters carry wrong Unicode values (the Wiley fonts of 10.1002_cvde.200390005) is decoded by a family table like a symbol font. A unit
or a table with an undecoded glyph is not checkable; a unit whose only words of 4+ letters hold undecoded glyphs is not checkable too,
never excluded as a unit without a word.

## Body check

Text layer: pdfplumber characters decoded with `glyph_codes.json`, read inside Marker's text blocks (Text,
SectionHeader, Caption, ListItem, TextInlineMath, Footnote; boxes shifted by the page box origin) as lines by the
baseline of the normal-size characters; small characters join the line whose baseline and size span they overlap,
superscripts marked `^`, stacked indices read subscript first; an Equation box's lines join the text unit before it for
the extra direction only; characters outside every block form segments of their own. Dropped or read once: characters
outside the page box, a character drawn twice on one baseline, a line printed twice on a page (the MDPI duplicate
layer). Excluded with a count: PageHeader, PageFooter, Figure, Picture, Diagram, Table, Form, Handwriting, Reference and
Code boxes; everything from a References, Acknowledgements, Funding, Author contributions, Conflicts, Associated
content, Supporting information or Data availability heading on (second half of the paper only); author and
affiliation blocks and author lines on pages 1–2; furniture (Published by, Cite as, doi, URL, ORCID, licence, article
id); running lines; segments holding only a number; the page abstract when the abstract comes from OpenAlex. On the
output side URLs, DOIs, received/accepted/published dates, ORCID ids, "Citation:" lines and table rows are removed
first.

Matching: a unit goes to the document.md paragraph sharing the most word 3-grams (at least a fifth of the unit's
3-grams, 2 at least; ties to the first paragraph after the last match), with the contiguous run of candidate
paragraphs around it; overlapping runs form one group. A short unit (under 4 words, or fewer than 3 tokens) and a line
the vocabulary test calls garbled (under 30 % of its words of 4+ letters in the output vocabulary, or two unknown
words of 8+ letters) are looked up near the previous match (3 paragraphs before to 10 after) after normalisation
(case, whitespace, markup, LaTeX commands, dashes, hyphenation at line ends), with and without spaces, a garbled
line also by similarity (85 % of its characters in matching runs of 3+, its letters then compared too); found, the
unit is checked as a normal unit and listed in `body_check.recovered`; else it is not checkable with the reason.

Numbers: both sides normalised as the table check does; a subscript joins its base (H2O), a superscript stands alone,
a number with a unit or a lowercase word glued to it counts as the number, a comma run is a list in one variant and a
thousands number in the other, Greek letters are letters of a run. Pure numbers are compared as multisets; mixed runs
(H2S, MoS3.0) by occurrence in the other side's text without spaces and markers. Display math and equation-like inline
math are the equation check's domain. Missing numbers (layer → output): one flag each, unless the group gathers several
units or repeated text and the number occurs within 3 paragraphs (a count mismatch), or the group's layer text is
repeated (presence only). Absent numbers (output → layer): one flag each, for output sentences covered by the layer
lines (70 % of their words of 4+ letters), with the neighbouring units' lines counting for the layer. An unmatched unit
with a number is "line not found in the output".

Flags (`body_flags`, one entry each): kind `number of the text layer missing from the output paragraph`, `number of
the output paragraph absent from the text layer`, `line not found in the output`, `letters of the text layer differ
from the output` (a similarity-matched line: the layer words absent from the paragraph with their closest output
words), and `not checkable`. Fields: page, number, layer_line, output_sentence, layer_numbers, output_numbers,
paragraph (raw chunk index of document.md), bbox, crop (`figures/body_p<P>_<k>.png`: the layer line when it can be
pinned down, else the whole paragraph block, `crop_scope`). A `not checkable` flag carries the reason and a crop:
layer side per unit with an undecoded glyph, per line of a short unit not found, per garbled line, per unit too short
to locate, per equation line with an undecoded glyph; output side per sentence the layer does not cover, per
paragraph blocked by an undecoded glyph in an equation or neighbour line, per paragraph a not-checkable unit also
matches (output text, the numbers left unchecked, a crop of the Marker block). Every line counted in
`body_check.counts.lines` is either checked or covered by a layer-side flag; every output unit counted as not
checkable carries an output-side flag (both identities hold on all 59 ingested papers). Output paragraphs with numbers that no
unit matches (reference entries, display equations, furniture) are counted, not flagged.

## Repairs (`body_repair.py`, born-digital pages only)

R1: in one paragraph a missing layer number and an absent output number that pair up unambiguously (same letters, at
most two characters and one in length apart, the layer token not glued to a minus sign) replace the output token;
each repair takes one distinct position (a pair that occurs n times goes to the first n occurrences, a repaired span is
never matched again). R2: a text-layer line of a Text, Caption or TextInlineMath block that no output paragraph
contains (8+ words, 70 % of its words in the document's vocabulary, no undecoded glyph, no reaction arrow) is inserted
after the paragraph the previous unit matched, marked "[restored from the text layer]". After the repairs the check
runs again; a repair whose sentence still carries a number flag (R1), or whose restored line is flagged again (R2), is
undone and recorded under `body_repairs_undone` with the remaining flag. `body_repairs` lists the applied ones (page,
kind, from, to, sentence or line, bbox). A page is born-digital when its text layer comes from embedded fonts (no OCR
font) and no image covers the whole page.

## Output

`final/<id>/document.md`; `final/<id>/structure.json` with paper_id, abstract, abstract_source, sections, n_pictures,
n_tables, captions (figures with images; tables with table, bbox, check, check_reasons, check_detail, crop), equations,
body_flags, body_check (counts, not_checkable_reasons, recovered, line_numbers, repairs, repairs_undone), body_repairs,
body_repairs_undone, sources; `final/<id>/figures/` (figure crops, table crops, flag crops). Intermediates kept for a
rerun without the vision models: `marker/<id>/` (blocks.json, marker.md and document.md, images, bands.json with its
band crops, structure.json, table crops) and `docling/<id>/equations.json`. Tracked: the seven pipeline scripts, the four report and check scripts, `glyph_codes.json`, `answers/` (Claude Code's
page judgements with ids and verdicts only: `tables.json` 90 tables, `equations.json` 254 items (every differ pair and single-tool item of the 58 papers judged
on the crop, the agree pairs of the first 13 papers accepted), `body_flags.json` 514 flag keys; `flag_keys_baseline.json`, the flag keys of the last accepted run), this file,
`ERRORS.md`, `NUMBERS.md`, `CHANGELOG.md`.

outside every total).

2 partly.

## Hand-off to the extraction stage

Ingest writes flags; it resolves none. The review at the start of the extraction stage (an external vision model,
scored on `ingest/answers/` before use) receives:

- a flagged table: the crop (`captions[].crop`), the markdown (`table`), `check_reasons` and the decoded layer text of
  the box (`check_detail.layer_text`); a `not checkable` table the same without reasons;
- an equation pair that is not `agree`: the crop rendered from `bbox` on the page, both LaTeX strings, the status;
- a body flag: the crop (line or paragraph block, `crop_scope`), the output sentence, the text-layer line, the numbers
  on each side, and for a letter flag the layer words with their closest output words; a `not checkable` flag the
  reason, the crop and (output side) the numbers left unchecked;
- the paragraph index, so the raw document.md paragraph can be shown unmasked.

Two rules for the review: the model must understand the content and judge from context, with a stated reason; it must
not copy what it sees. The flags of one error are grouped and judged together: one error can raise flags in both
directions and on several lines (a number missing from the output and the same error's token absent from the layer,
several tokens of one citation list, a paragraph crop shared by several flags).

What the review must know about the inputs is in `ERRORS.md` (lookalike letters, symbols not compared, source
typos, the representative line in the flag text, the MDPI duplicate layer).
