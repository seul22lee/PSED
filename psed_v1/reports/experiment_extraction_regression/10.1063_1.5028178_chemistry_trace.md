## The exact line

[`05_figure_extract.py:369-384`](../../03_corpus/scripts/05_figure_extract.py#L369-L384):

```python
for s in p.get("series", []):
    lab = (s.get("label") or "").strip()
    _cls, _match = _classify_label(lab, mats)      # mats = scout["materials"]
    if _cls == "empty":
        material = (mats[0] if mats else None)     # <-- line 375
    elif _cls == "material":
        material = _match                          # only path that is evidence-based
    else:
        material = (mats[0] if mats else None)     # <-- line 383
```

Fig. 7's series labels are `Fitting result` and `Measured`. Neither is a
material, so `_classify_label` returns the `else` branch and line 383 assigns
`mats[0]` = `"Al2O3"`.

**Material is recoverable only from a series legend.** The caption is never
parsed for chemistry at any stage of the pipeline.

## The chemistry resolver is not at fault

Called directly with the same `card` and `scout` for this paper:

```
resolve_experiment_chemistry("Al2O3") -> TMA  , H2O, fully_resolved, material_element_match, 0.7
resolve_experiment_chemistry("TiO2")  -> TiCl4, H2O, fully_resolved, material_element_match, 0.7
resolve_experiment_chemistry(None)    -> None , H2O, ambiguous     , unresolved_multi_material, 0.0
```

Given the right material it returns the right precursor, and given *no* material
it correctly refuses. `chemistry_propagation.py` was written specifically to
stop list-position guessing ("Al2O3 gets TMA, not DEZ"); the identical bug it
was built to prevent survives one stage upstream, where nothing guards it.

Handing the resolver `None` instead of a wrong material would already yield the
honest `ambiguous / unresolved_multi_material` outcome.

## Control case

`10.1021_acs.jpcc.9b08176` has 4 materials in `scout.materials` and **all 4**
appear in its records — because its series legends are literally `SiO2`,
`TiO2`, `Al2O3`, `HfO2`, taking the `_cls == "material"` branch.

This isolates the mechanism: the pipeline can carry per-figure material
correctly, but only when the material happens to be a legend label.
