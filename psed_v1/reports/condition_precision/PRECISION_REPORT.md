# Condition-binding precision validation

> **Re-run after the experiment-extraction repair.** Both samples were re-drawn
> from the regenerated bindings and re-verified against the corrected entities,
> so this reports the CURRENT pipeline, not the pre-repair one. The population
> and the case-inheritance figures changed; precision did not.

Scope: are the condition assertions the pipeline **did** bind correct? This is a
precision audit. Completeness and recall are measured by a different artifact
(`reports/condition_completeness/`) and are reported separately in the last
section, never mixed into the precision figures — a pipeline can raise recall by
binding more and worse, and averaging the two hides exactly that trade.

Everything below is regenerated by:

```
reports/condition_precision/sample.py [seed] [suffix]      # draw
reports/condition_precision/verify.py [suffix]             # re-derive 7 criteria from source
reports/condition_precision/estimate.py [suffix]           # HT + cluster bootstrap
reports/condition_precision/ambiguity_census.py            # withheld groups, census
reports/condition_precision/unresolved_metric.py           # the 46/72 decomposition
```

Two independent draws of n=150, the second held out and drawn *after* every

| draw | seed | rows | papers | correct | errors |
|---|---|---:|---:|---:|---:|
| primary | 20260804 | 150 | 21 | 150 | **0** |
| held-out | 771103 | 150 | 21 | 150 | **0** |

The two draws overlap in only 13 rows, so together they check **287 distinct
assertions (14.2 % of the population)** with no error found.

Per criterion (primary draw; held-out is identical except c2/c5 unverifiable = 3
and c6 not-applicable = 3):

| criterion | pass | fail | unverifiable |
|---|---:|---:|---:|
| c1 value + unit match the source | 150 | 0 | 0 |
| c2 quantity typing | 146 | 0 | 4 |
| c3 applicability to the bound entity | 150 | 0 | 0 |

| c5 assertion status (direct/approximate/…) | 146 | 0 | 4 |
| c6 species / reactant attribution | 150 | 0 | 0 |
| c7 no duplication of another assertion | 150 | 0 | 0 |

"Unverifiable" means the verifier could not re-derive the criterion
independently (the governing phrase is outside its window), not that the binding
disagreed. They are reported as neither pass nor fail rather than being counted
as successes.

### Population estimate

Stage 1 of the sampler forces one row from every stratum, so rare strata are
heavily over-sampled and a raw 150/150 does **not** describe the corpus. The
Horvitz–Thompson ratio estimator reweights each row by its stratum's population
share:

- **HT precision point estimate: 1.000**

The paper-level cluster bootstrap (10,000 replicates, resampling the 21 papers
with replacement) is **degenerate here**: with zero observed errors every
replicate is also all-correct, so it returns [1.000, 1.000]. That interval is an
artifact of having seen no failures, not a measurement, and is reported as
`null`. The honest statement is a zero-failure bound:

| assumption | bound on the corpus error rate |
|---|---|
| rows independent (n = 150) | ≤ 2.0 % |
| complete within-paper correlation (n = 21 clusters) | ≤ 14.3 % |

The truth sits between them. The cluster bound is deliberately pessimistic —
assertions in one paper share a docling conversion and a parser path, but they
are not literally one observation.

## 2. Error categories found and fixed

The audit began at **125/150**. Every failure was traced to one of four causes.
Only causes 1–3 were parser errors; the parser was changed only for those, per
the instruction not to change it without a reproducible error.

| # | error | mechanism | blast radius | status |
|---|---|---|---|---|
| 1 | negative exponents inflated 10× | docling renders `10⁻⁷` as `10 /C0 7`; the normalizer produced `10e-7` (= 1e-6) instead of `1e-7` | **62 bound assertions** (34 in `c7ra07722j`, 28 in `pssa.201532305`) | fixed |
| 2 | carrier-gas flow on the wrong species | `"100 sccm of H2-carrier gas (Ar)"` attributed the flow to the *carried* gas, not the carrier | 2 assertions | fixed (one now yields no species — under-attribution, never a wrong species) |
| 3a | one unit, two spellings | docling emits both `150 °C` and `150 ° C`; the identical value then escaped specialisation dedup and surfaced as a duplicate typed both `temperature` and `deposition_temperature` | 1 pattern, plus `Å per cycle` vs `Å/cycle` withheld as a false conflict | fixed — `_norm_unit` folds whitespace, `° C`, and `X per Y` |
| 3b | stoichiometry read as a measurement | the pulse-time governing phrase reaches ~30 characters, far enough to swallow the precursor formula: `dose times [Mo(iPrCp)2H2]` → pulse time of **2 hours** | **70 spurious assertions** | fixed — `_in_chemical_formula` rejects a single-letter unit whose digit abuts a formula character |
| 4 | verifier artifacts, not data errors | `series_axis` not passed to the re-derivation (6); status window wider than the parser's (2); species compared only to the first match (2); `"%g" % 1e-7` → `"1e-07"` never matches the source text (12); caption slice used the preamble while the parser reads the full caption for pressures (4) | 26 false failures | verifier fixed; no parser change |

Cause 3b is the one worth remembering: it produced values that were *plausible*
(a 2-unit pulse time) and would have survived any range check. It was caught
only because the ambiguity census surfaced `2 H` sitting next to `15 s` as
competing candidates.

Net effect of the fixes on the bound population: **1,915 → 2,028** assertions.
The increase is not new extraction — it is the 70 spurious candidates no longer
blocking their groups as false conflicts, plus unit-spelling collisions resolved.

## 3. Withheld ambiguous assertions — a census, not a sample

The 553 withheld rows in the completeness matrix are not 553 independent
decisions. They collapse to **58 distinct (paper, quantity, species, scope,
candidate-set) patterns**, replicated across entities that share a scope. That is
small enough to adjudicate exhaustively, so this is a **census with no
extrapolation**.

(The census counts 583 entity-condition rows against the matrix's 553: the
matrix keys a row by (entity, quantity) while the census keys by
(entity, quantity, species), so per-reactant groups that the matrix merges are
counted separately here. Both cover the identical set of withheld groups.)

| | patterns | entity rows |
|---|---:|---:|
| ambiguity is scientifically real | **58** | **583** |
| a deterministic rule could safely resolve it | 0 | 0 |
| the candidate was generated spuriously | 0 | 0 |

Two structurally different kinds of real ambiguity are present:

**(a) Genuinely competing values at one scope** — the methods state two settings
and nothing narrower selects one. Examples verified against the papers:

- `bjnano.5.25` — methods state depositions "performed at 200 °C" *and* "at
  225 °C"; nothing ties either to a given figure.
- `c7ra07722j` — `20 mTorr` reactor pressure during dosing vs `13 mTorr` during
  O₂-plasma generation. Both are true; which applies depends on the sub-step.
- `6.0002436` — `200 °C` set-point vs a `100–300 °C` variation.

Binding either would fabricate an attribution the paper does not make.

**(b) The varied-axis guard** — the quantity is the figure's own swept variable,
so a broad-scope value cannot be pushed onto an individual point of the sweep
("temperature was varied from 200 to 350 °C" must not become 350 °C on every
entity). These appear as single-candidate withholds and are refusals to
broadcast, not unresolved conflicts.

Two patterns *did* turn out to be resolvable and were fixed rather than
excused — the `Å per cycle`/`Å/cycle` unit-spelling conflict (cause 3a) and the
`2 H` formula fragment (cause 3b). Both are gone from the census; the remaining
58 are irreducible without new evidence.

## 4. The `46 / 72 unresolved entities` metric, decomposed

The original ratio divided entities that happen to carry a condition by *all*
unresolved entities, including those for which the source states nothing
applicable. Those can never move the numerator, so the ratio understated
retention by construction. The three requested counts:

| count | meaning |
|---:|---|
| 72 | unresolved source entities in the corpus |
| **48** | **(a)** have at least one applicable condition in the source |
| **23** | **(b)** of (a), retained *every* such condition |
| 25 | of (a), did not retain all — 23 retained some, 2 had every candidate withheld |
| **24** | **(c)** the source supplies no applicable condition at all |
| 46 | carry ≥1 bound condition — the old headline numerator |

(a) + (c) = 72 by construction, asserted in the script.

So the correct reading is: of the 48 unresolved entities that *can* carry a
condition, 23 retained everything applicable, 23 retained part with the
remainder withheld as genuinely ambiguous (section 3), and 2 had every
applicable candidate withheld — 46 with at least one bound condition, matching
the old numerator. Nothing was discarded in any of the three groups; withheld
candidates remain attached to the entity. The 24 in (c) are not a shortfall —
the papers state no applicable condition for them, so the honest denominator for
retention is 48, not 72.

Unresolved entities are unresolved because the classifier saw conflicting or
single-family signals, not because conditions were missing:

- only one signal family — 35
- conflicting signals — 37

## 5. Completeness and recall — reported separately

These numbers are **not** combined with the precision figures above.

| | |
|---|---:|
| condition rows tracked end-to-end | 2,517 |
| bound | 1,964 |
| withheld as ambiguous (candidates preserved, never discarded) | 553 |
| bound and inherited by an experimental case | 1,142 / 1,142 |
| bound on entities with no case (simulation / literature / unknown) | 822 |
| conditions attached to a mis-materialised entity | 0 |
| visible in the knowledge graph | 1,964 / 1,964 |
| first missing downstream stage | none |

Recall against the source text is *not* claimed here. This audit establishes
that what was bound is right and that what was withheld was rightly withheld; it
does not establish that nothing was missed. The under-attribution introduced by
the carrier-gas fix (one flow now carries no species rather than the wrong one)
is a deliberate recall loss taken to protect precision.
