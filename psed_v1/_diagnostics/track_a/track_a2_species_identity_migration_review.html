There is no case-ID migration to perform. case_id is a positional index assigned when the case is built; nominal_fingerprint is computed afterwards from the finished cases. A species change moves the fingerprint and cannot move the id, so no reference rewrite exists to perform. So this batch is a semantic correction plus a fingerprint relabel; nothing references a fingerprint, and every reference points at a case ID that did not move. Referential integrity is preserved by construction, not by rewriting.

Why attribution changed distinguishability

Conditions are de-duplicated per case on (quantity, species). A swept Precursor Pulse value therefore collided with a methods-default pulse_time carrying no species, and the methods number won — the swept value, which is the entire subject of that figure, was being discarded. Giving the precursor condition its own species gives it its own key, so the sweep survives. Ten cases the source distinguishes by precursor pulse length are distinguished again: DISTINGUISHED 120 → 130, INDISTINGUISHABLE 62 → 52. No case was created, destroyed, split or merged.

Species match precision

Attribution used to accept a reagent that merely occurred as a substring of the label, so H2 matched H2O dose and Mo matched MoCl2O2 pulse. Nothing in the corpus was actually mis-attributed — a longer reagent happened to be present and outranked the fragment — but longest-match was hiding the bad candidate rather than excluding it, so the guarantee rested on an accident of each paper's inventory.

A reagent must now occupy a complete chemical span: neither end may run into a character that continues a chemical token — a letter or digit either side, an opening bracket on the right (a ligand follows, so Y is not Y(sBuCp)3), a closing bracket on the left, or a hyphen (at-H is not H). Enclosing punctuation is not continuation, so a parenthesised (Pt(acac)2) still matches. Longest-match remains, but now only ever chooses between readings that are each already complete.

The same normalisation made two printed forms legible that the raw matcher could not see: H₂O dose and CO₂ dose now resolve to H2O and CO2. Across unseen and support papers: 0 attributions lost, 0 species changed, 2 recovered, and 0 false partial matches existed to remove.

Attribution provenance scope

The 17 active-8 additions were recorded as LOCAL_ROLE_EXPLICIT, which overstated what was known. The role is explicit and local — the axis says Precursor Pulse (s) — but the species is not named anywhere local; it is reached because the paper's inventory lists exactly one precursor. Those are different evidence scopes, so the tier is now ROLE_LABEL_PAPER_UNIQUE: the label names the role, the paper names the chemical. All 17 were checked rather than bulk-relabelled — they share one mechanism, two axis labels, one inventory entry (Y(DPfAMD)3), and no local caption or body text names the species itself. Species values, fingerprints, case IDs and topology are byte-identical to the reviewed candidate; only the provenance label moved. EXPLICIT_LABEL_SPECIES remains reserved for a label that names the chemical outright, and LOCAL_EXPLICIT_SPECIES for local evidence that does.

Deferred

Kept out of A2 deliberately: species-aware comparability and query; the flow_ratio ontology gap; ambiguous common-name normalisation (Alcohol, at-H, LiOᵗBu); electrode_potential, vapor_pressure, critical_angle. Separately noted for a later batch: in one paper the source recipe states precursor purge durations that upstream extraction typed as pulse_time. A2 neither creates nor repairs that — correcting it needs re-extraction, not a species rule — but attribution makes it visible.
