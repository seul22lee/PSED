Recipes in the KB, and a literature warm-start for control

Every experiment is lifted into an actionable Recipe — the object the LLM agent and the MPC twin both speak — with missing fields filled from the KB literature / model cascade. The controller then seeds itself from the nearest literature process instead of a cold guess.

2 · Target dose by twin inversion

Given a target penetration depth and a fixed pressure-to-pulse-time ratio r = pA/t_p = 1000 Pa/s (source: fallback), the dose D = pA·t_p is solved directly from the twin by bracketed root finding (brentq) — not by a controller and not by gradient descent. Feasibility is decided from the achievable PD range before solving. The literature reference dose is shown for comparison; it is a ratio prior, so the solved dose is model-inverted under a literature-informed ratio, not itself literature-derived.
