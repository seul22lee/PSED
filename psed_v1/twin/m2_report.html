A feasible operating region was found for depositing Al2O3 to a 60.000 µm penetration depth in a lateral_channel feature using TMA + H2O. The design is classified exploratory.
Why this classification:
  • kinetics_not_chemistry_specific — twin kinetics are 'partial_chemistry'; the sticking / adsorption / GPC coefficients are not resolved for this exact chemistry
  • kinetic_uncertainty_withheld — band reflects geometry/temperature scatter only; the kinetic parameters ['c', 'K', 'gpc'] are model defaults without σ, so absolute target-hit credibility is withheld
A quantitative design requires chemistry-specific kinetics, a valid geometry, a reachable target and propagated evidence uncertainty. Anything less is reported as exploratory — the same structured result, with quantitative confidence withheld.
